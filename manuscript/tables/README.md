# Current and historical generated tables

The current [numerical records and generated tables](../../results/column_publication_20261025/tables/) adopt the completed Column logical-domain/B13 runs on top of the CSTR30 initialization update.
run_records.csv, process_hits.tex and process_cost.tex are byte-identical copies from that analysis.
paired_comparisons.csv retains the original 25 Grid rows and replaces the historical Process rows with the current 28 condition-specific comparisons.
The preceding versions of these four files are preserved under [review history](../review_history/pre_column_adoption/tables/).
Every other pre-existing file in this directory remains a historical companion and is not a complete representation of the current Process cohort.
In particular, numerical_summary.json, process_intervals.tex, process_tts.tex and rbfopt_process_variants.tex retain their original cohorts.
The current main and supplementary sources embed their displayed tables directly and do not load these generated TeX files.
See the [current manuscript README](../README.md) for the adopted comparison and reproduction commands.
