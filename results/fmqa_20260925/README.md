# FMQA results index

The default **FMQA-SA** now uses the [QHD PyTorch dataset and current figures](../fmqa_qhd_20261012/README.md).

The September `grid/` and `case/` summaries are **FMQA-SA (NumPy legacy)**.
Run settings, CSVs, manifests and figures remain directly readable. Detailed
`jobs/` and frozen `source/` files are preserved unchanged in the original
ZIPs instead of duplicated in this checkout. See the
[verification and extraction guide](../archives/README.md#reviewing-detailed-records)
and [legacy archive index and pre-QHD figure snapshot](../fmqa_numpy_legacy_20260925/README.md).

Existing Grid image URLs continue to point to the current [Grid GDP path-cost analysis](../grid_gdp_dfo_20261011/README.md). Historical lookup tables and convergence figures in this directory describe the NumPy implementation and are not inputs to the current plots. Current [process plots and tables](../dfo_trace_nlp_20261002/README.md) also use QHD.
