Companion data for the supplementary material. success_intervals.csv contains 476 problem/method/budget rows with pointwise two-sided exact binomial 95% intervals, n=10. protocol_*.json preserve selected process settings and initial designs. Grid source archives are identified separately. grid_inventory.json contains full precision implemented raw-grid extrema, exact floating minimizing indices and all target indices; analytical ties can be split by rounding. process_model_counts.json counts the unfixed GDP including all active disjunct branches before reformulation; Dynamic is discretized. fmqa_proposal_counts.csv counts candidate proposals separately from objective evaluations. Exact auxiliary solver version strings not present in the archive are not inferred.

process_nlp_acceptance.json documents the process response acceptance predicate and identifies initialization artifacts and provenance. fmqa_fallback_by_family.csv pools per-run proposal counts by family.

terminal_callback_recovery.json documents the 14 terminal-only target configurations preserved in the original final run summaries, with exact archive-member paths, objectives, coordinates, and SHA-256 provenance. It distinguishes wrapper-reported configurations from unavailable native optimizer return objects.

Stopping diagnostics (Supplementary Section S4.4): stopping_diagnostics.json contains 4,760 run-level records, 476 condition-level summaries, eight pooled family/method summaries, source hashes, and classification notes. stopping_diagnostics.txt is the compact English summary. These diagnostics are calculated from the selected execution records. Native reasons absent from the original records are not inferred.
