CSTR-only IPOPT CSV DFO experiment for Dantzig

240 slots: N/B = 5/8, 10/15, 15/22, 20/29, 25/36, 30/43;
four methods (RBFOpt, BAM, budget-limited DSDA, FMQA-SA), seeds 0..9.
Two integer coordinates each range from 1 through N. No feasibility mask.
No non-CSTR runner, source, input or output is changed by this bundle.

Algorithms, starts and budget
  Original three ordered LatinHypercube integer starts for each N/seed. The
  generated designs are checked against both frozen FMQA and DSDA reference
  plans. Identical starts across all four methods; no feasibility resampling.
  RBFOpt: MSRSM, global_search_method=solver, rbf=auto, rand_seed=seed.
  BAM5: x0=None, integer variables, three pre-evaluated starts, max_evals=B-3;
  native internal solver/defaults unchanged. Python/NumPy seeded; original BAM
  runner exposes no separate native seed option. Native output is saved.
  DSDA: full box, best accepted of the three observed starts, diagonal=True,
  first tie, tolerance1e-12, max_points_explored=B-3. No accepted start -> failure.
  FMQA-SA: original QHD_Data PyTorch surrogate, 1000 epochs, learning_rate=.01,
  SA100 reads/1000 sweeps/geometric, three SeedSequence streams, 1800s soft limit.
  Every method's actual options, environment and shared starts are saved.
  Failure representation: RBFOpt/DSDA +inf, BAM NaN, FMQA +inf (report1e6,
  observed-training penalty2). No new finite penalty introduced for CSTR.

  Every original-process callback counts, including initial/failed/repeated
  calls. Internal surrogate evaluations and cache hits without callbacks do not.
  Hard stop in callback B occurs after recording its objective, status and cost.
  The terminal callback raises BudgetStop instead of returning a numeric value;
  value_returned_to_optimizer=false and callback_exit=budget_stop are explicit.
  Final best is the best accepted observation in the durable callback ledger,
  including observation B. This prevents restart batches from exceeding B.
  Search paths are newly generated. No historical paths are relabeled.
  Failed seeds remain failed; no replacement seeds or retries.

Allowed solvers
  RBFOpt's original Bonmin/IPOPT surrogate calls and BAM's native BARON-based
  surrogate optimization remain enabled. Auxiliary solver cost is DFO time.
  No original process GDP/NLP is built or solved, no IPOPT process reevaluation,
  no enumeration, no GDPopt edits, no solver installation or environment updates.
  Executable process models and legacy lookup tables are absent from the bundle.

Time and reports
  DFO wall time includes imports at optimizer entry, learning, candidate and
  auxiliary solver work, callbacks and trace IO. Input loading and environment
  checks are outside this clock. Worker process wall time is recorded separately.
  Historical NLP setup/preprocess/feasible-initialization/solve/total/worker times
  come only from the same CSV row and original attempt as the objective.
  Repeated callbacks charge repeated historical costs; unique-attempt and all-
  attempt sums are separately labeled. Here every coordinate has one attempt.
  Missing breakdowns stay null. N30 unmeasured exclusions have no total time.
  N5..25 logical exclusions have measured total and solver time0 (no NLP call),
  but their missing setup/preprocess breakdowns are not filled with zeros.
  CSV lookup time is never presented as newly measured NLP execution time.

  Table accepted minima are reporting targets, never global GDP optimum claims:
    N5 3.0620145766081155; N10 2.889536968602369;
    N15 2.8293940630895253; N20 2.7994064251078212;
    N25 2.7814825926752516; N30 2.7695697198995095. Each minimum is at [N,N].
  Targets and full-table statistics are never passed to algorithm initialization,
  candidate selection or stopping. Published report tolerance source:
  process_dsda_fairness.py:300, abs(best-target)<=1e-5*max(1,abs(target)).
  target_reached / target_not_reached / execution_failed / not_run are separate.
  Failed execution with a prior target observation stays execution_failed.
  Ten-seed denominator includes failures; any not_run leaves the group rate null.

Dantzig execution
  Use the existing .venv-dantzig-nlp-overnight and .venv-dantzig-fmqa-qhd.
  Missing/mismatched method environment -> not_run; other methods proceed.
  Overrides: IPOPT_DFO_REPOSITORY, IPOPT_DFO_PYTHON, IPOPT_FMQA_PYTHON,
  IPOPT_DFO_CONDA, COIN_BIN, BAM_LICENSE_FILE. No license file is bundled.
  Sequential isolated workers, one logical CPU, numerical threads1, CPU PyTorch.
  Read-only /proc checks exclude running non-CSTR DFO and CSTR NLP jobs' CPU
  affinities and all their physical-core siblings. Other jobs are never modified
  or signalled. --cpu N must pass the same check. If separation is impossible,
  no searches start. Affinity is not an exclusive reservation against other users.
  Controller/children inherit the selected CPU. Hard watchdog2100s per slot.

  Inside the extracted ipopt_dfo_cstr_runner directory:
    sha256sum -c SHA256SUMS
    nohup bash run_ipopt_dfo_cstr_dantzig.sh run > launch.log 2>&1 < /dev/null &
    tail -f launch.log
  Optional check mode verifies inputs/environments without any optimizer/solver.
  It creates a separate check directory. Use run for the actual experiment.

  failed, and launches only genuinely unstarted slots. No existing results are
  overwritten. Changed inputs or environments require a new identified run.
