3. 연구 방법과 비용 정의
Column/CSTR/Dynamic의 DSDA에서 유한 lookup 값만으로 후보를 제한하던
필터를 제거했다. 공통 bounds 내부의 unsuccessful/infeasible 평가도 실제
콜백과 예산에 포함한다. 기존 시드별 순서의 초기점3개, 예산, 이웃 순서,
tie-breaking, line search, 엔진 tolerance1e-12는 유지했다.
Small Batch는 기존 full-domain 경로를 유지한 회귀 확인이다.
마지막 seed9 문제는 엔진의1e-12 개선 허용오차를 무시한 exact-equality
검증기 오류였다. optimizer crash나 새로운 target hit로 표현하지 마라.

성공 여부는 독립 lookup target 기준이다. NLP 측정의 accepted 여부와
구분하라. completion 비용은 recorded method time - lookup callback time
+ 모든 콜백의 기존 실측 비용 + Dynamic 기준 preparation1회이다.
초기점과 반복 방문도 각각 과금한다. 고정 경로의 비용 재구성이며 온라인
NLP wall time 또는 최초 목표 도달 시간으로 표현하지 마라.
TTS99는 실패 시드까지 포함한10개 completion 비용의 median에
ceil(log(0.01)/log(1-p))를 곱한다. p=0이면 infinity, p=1이면1회이다.
성공 시드만의 median이나 평균값으로 대체하지 마라.

CSTR 동일 좌표의 기존 preprocessing_infeasible 비용 재사용을 유지하라.
CSTR20(6,7) <- CSTR30:0.20002566697075963초
CSTR20(17,19) <- CSTR30:0.1995336510008201초
CSTR25(22,24) <- CSTR30:0.2000632556155324초
CSTR30(13,15) <- CSTR20:0.6212939228862524초
마지막 항목은 CSTR20 실측이며 CSTR30 직접 측정으로 표시하지 마라.
요청 크기·측정 크기·원본 archive/member/SHA256을 보존하라.
solve_wall_s=0이어도 측정된 total_wall_s는 양수다. 0초 대입이나 새로운
측정으로 대체하지 마라. 기존 exact 비용과 다른 좌표의 값은 바꾸지 마라.

4. 실제 수행할 원고 갱신
기존 process publication 작업물이 있으면 그 작업을 이어서 갱신하라.
results/process_dsda_publication_20261014/와
scripts/render_process_dsda_update.py가 있다면 이전139건 전용 입력,
PENDING seed9, 임시 placeholder, CSTR15 통계 억제 로직을 최종 데이터로
바꾸어 모든 산출물을 다시 생성하라. 단순히 pending 문구만 지우지 마라.
원본139건 기록과 오류 ZIP은 역사적 증거이므로 덮어쓰지 마라.

현재 원고의 실제 label/참조를 찾아 process Results 본문, target-attainment
표·피겨, 평가 횟수 곡선, completion-time/TTS99, 비용 구성 피겨와 캡션을
같은560개 선택 기록으로 일관되게 수정하라. Figure 번호를 추측하지 마라.
기존 Grid DFO/GDPopt/BARON 결과와 Grid GDP 표는 이번 작업에서 변경하지 마라.
다른 방법420건의 원래 결과와 수치는 그대로 보존하라.

old_vs_new_summary.csv로 결론 변화도 반영하라. 특히 DSDA target hits는
Column8→6, CSTR5 3→2, CSTR10 3→2, CSTR30 5→2,
Dynamic B20 9→8이며, Small Batch8/10은 유지된다. CSTR15도2/10 유지다.
다른 그룹과 시간 수치는 실제 CSV에서 확인하고 우열 결론을 재검토하라.

최종 표, PDF 피겨, plotting script, 입력 CSV, provenance manifest를 남겨라.
복구 ZIP hash, 보존 검증, 사용 데이터와 스크립트 hash를 추적 가능하게 하라.

캡션·본문·표의 수치를 대조하여 시각 검수하라. 복구 대기 안내와 placeholder가
현재 결과나 원고에 남지 않도록 하되 역사적 원본 기록은 유지하라.
Overleaf에 반영하고 컴파일하라. 연결이 없으면 바로 붙여넣을 LaTeX 본문·표,
적용 가능한 patch, figure 파일과 교체 경로를 제공하라.
마지막에 변경 파일, 수치와 결론 변화, 컴파일 결과, 남은 실제 작업을 보고하라.
