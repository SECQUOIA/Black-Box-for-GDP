DSDA 수정:
Column/CSTR/Dynamic의 유한 lookup 값만을 이용한 후보 도메인 제한을 제거했다.
공통 bounds 안의 unsuccessful/infeasible 평가도 실제 콜백과 예산에 포함한다.
시드별 기존 순서의 초기점3개, 예산, 이웃 순서, tie-breaking, line search,
엔진 tolerance를 유지한다. 초기 평가와 반복 콜백도 모두 과금한다.
재시딩하거나 목표 도달 후 임의 종료하지 않는다. Small Batch는 기존
full-domain 경로의 회귀 확인이며 도메인을 축소하지 않는다.

CSTR infeasible 비용은 재측정하지 말고 기존 동일 좌표의 실측값을 재사용하라.
기존 비용은 유지하고 아래 네 누락 연결을 채운다.
- CSTR20 (6,7): CSTR30의0.20002566697075963초
- CSTR20 (17,19): CSTR30의0.1995336510008201초
- CSTR25 (22,24): CSTR30의0.2000632556155324초
- CSTR30 (13,15): 현재 확인된 CSTR20의0.6212939228862524초
마지막 항목을 CSTR30 직접 실측으로 표시하지 마라. 요청 크기·측정 크기,
archive/member/SHA256을 남겨라. 네 항목은 preprocessing_infeasible이며
solve_wall_s=0이지만 total_wall_s는 양수다.0초 대입, 임의 평균, 다른 좌표
대체, 추가 NLP 실행을 하지 마라. 더 완전한 기존 CSTR30 자료가 발견되면
검증 후 명시적으로 갱신하라.

성공은 독립 lookup target 기준이다. 비용은 method time - lookup callback
time + 모든 콜백의 선택된 실측 비용 + Dynamic 기준 preparation1회이다.
반복 콜백도 방문 횟수대로 더한다. 고정 경로의 completion 비용 추정이며
온라인 NLP 실행 시간이나 최초 목표 도달 시간으로 표현하지 마라.
TTS99는 기존 정의를 유지한다: 실패 시드도 포함한10개 completion median에
성공확률 기반 restart 수를 곱한다. 누락 그룹에서 subset median을 쓰지 마라.
RBFOpt/BAM/FMQA의420개 선택 기록과 실행 결과를 보존하라.
Grid DFO 및 GDPopt/BARON 결과와 이미 수정된 Grid GDP 표는 변경하지 마라.
